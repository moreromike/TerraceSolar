# Runway review folder

Media generated by hand in the Runway **web** application and downloaded here for review.
Nothing in this folder is produced by an API call.

- `keyframes/` — the 11 boundary stills, K0 through K10.
- `segments/` — the 10 video segments, S1 through S10 (only after all keyframes are approved).

Naming: `K0.png`, `K1.png` … `K10.png`, and `S1.mp4` … `S10.mp4`.
Keep the original download; if you regenerate, save as `K0-v2.png` rather than overwriting.

Prompts, references and acceptance notes: `../../assets/video/STORYBOARD.md`
